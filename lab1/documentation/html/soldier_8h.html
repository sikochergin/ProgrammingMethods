Описание класса Soldier и операторов сравнения.

Файл содержит класс Soldier, который используется для хранения информации о служащем воинского полка. Также здесь перегружаются операторы сравнения, необходимые для работы алгоритмов сортировки.

◆ getRankPriority()

int getRankPriority ( const string & rank)

Возвращает числовой приоритет воинского звания.

Чем меньше число, тем ниже звание. Такая функция нужна для того, чтобы сравнивать звания не по алфавиту, а по их старшинству.

Аргументы
rankВоинское звание.
Возвращает
Числовой приоритет звания.

◆ operator<()

bool operator< ( const Soldier & left,
const Soldier & right )

Оператор "меньше" для сравнения двух служащих.

Сначала сравнивается звание по старшинству. Если звания одинаковые, сравнивается ФИО. Если ФИО также одинаковые, сравнивается номер роты.

Аргументы
leftПервый служащий.
rightВторой служащий.
Возвращает
true, если left должен стоять раньше right.

◆ operator==()

bool operator== ( const Soldier & left,
const Soldier & right )

Оператор "равно" для сравнения двух служащих.

Два служащих считаются равными для сортировки, если у них совпадают звание, ФИО и номер роты.
