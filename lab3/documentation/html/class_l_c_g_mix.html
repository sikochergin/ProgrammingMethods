Подробное описание

Модифицированный линейный конгруэнтный генератор.

Базовая формула линейного конгруэнтного метода: state = (A * state + C) mod M

В данной реализации используется тип uint32_t, поэтому при переполнении лишние старшие биты автоматически отбрасываются, также нужен ровно 32-битный беззнаковый тип.

Это то же, что и работа по модулю: M = 2^32

Модификация заключается в том, что генератор возвращает не само состояние, а его дополнительно перемешанную версию.

uint32_t LCGMix::next ( )
inline

Генерирует следующее псевдослучайное число.

Сначала обновляется внутреннее состояние по формуле LCG: state = A * state + C

Из-за типа uint32_t переполнение работает как взятие по модулю 2^32. Затем состояние дополнительно перемешивается функцией mix().
