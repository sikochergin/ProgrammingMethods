◆ buildMultiMap()

multimap< string, Soldier > buildMultiMap ( const vector< Soldier > & soldiers)

Строит стандартную структуру multimap для поиска по ФИО.

В multimap ключом является ФИО солдата, а значением - объект Soldier.

multimap используется потому, что одинаковое ФИО может встречаться у нескольких объектов.

Аргументы
soldiersВектор солдат.
Возвращает
multimap<string, Soldier> Структура для поиска по ФИО.

◆ searchInMultiMap()

vector< Soldier > searchInMultiMap ( const multimap< string, Soldier > & mp,
const string & key )

Выполняет поиск всех солдат с заданным ФИО в multimap.

Для поиска используется метод equal_range, который возвращает диапазон всех элементов с ключом key.

Аргументы
mpГотовая структура multimap.
keyФИО, которое нужно найти.
Возвращает
vector<Soldier> Вектор найденных солдат.
