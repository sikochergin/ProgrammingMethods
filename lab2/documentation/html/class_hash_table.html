Ключом является поле fullName.

◆ insert()

void HashTable::insert ( const Soldier & soldier)
inline

Добавляет одного солдата в хэш-таблицу.

Если ФИО уже есть в таблице, солдат добавляется в существующий список values.

Если ячейка занята другим ФИО, используется линейное пробирование.

Аргументы
soldierСолдат, которого нужно добавить.
